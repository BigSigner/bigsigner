BigSigner is a multisig-first wallet, built to make the usual ways of losing funds harder. You need to understand the basics of how Bitcoin wallets work before you use it.

Here is the terminology you need to know:

Seed Key

If you are here, you already know what this is. A passphrase is part of the seed. The same 24 words with a passphrase are a completely different seed from those 24 words without a passphrase.

Fingerprint

A fingerprint is an 8-character identifier for a seed. It does not reveal the seed itself. A wallet app on a phone or computer uses it when it talks to the hardware wallet. In a multisig wallet, for example, it says which seed must sign, and where. Two randomly generated seeds can share a fingerprint, which would be a problem in a multisig wallet that included both of them, but the odds are extremely low.

Fingerprint Name

An easy-to-remember name calculated from the fingerprint. It is an adjective, a color, an animal, and the last two characters of the fingerprint. For example, the name for 1a2b3c4d is Isolated Chocolate Boar 4D.

External Key

The fingerprint from another hardware wallet that holds the private seed, together with a type, account index, and their matching xpub (see below). You can use it in a multisig wallet, or as a watch-only wallet: you can see that wallet's addresses, but you cannot spend from them.

  • The supported types are Native-Segwit SingleSig, Native-Segwit MultiSig, and Taproot SingleSig. BigSigner does not let a key be used for a type other than the one it was made for.
  • Account index: a number that derives different keys from the same seed and the same type. The default is 0. In a singlesig wallet, this can keep coins received from different sources apart, to avoid accidental mixing. BigSigner will not sign a transaction whose inputs come from more than one account. You would have to move the bitcoin from account A to account B, and then spend from account B. Some wallet apps hide non-zero account indexes as an advanced feature, because a less technical user may forget which account index they used and think the funds are lost.
  • xpub: an extended public key. It lets you find the addresses for one type and one account index without knowing the Seed Key. In a multisig setup, each hardware wallet must have the xpubs generated by the other hardware wallets, in order to calculate the addresses of the multisig wallet.

SingleSig Wallet

A fingerprint together with a type: Native-Segwit SingleSig or Taproot SingleSig. If the matching Seed Key is loaded, you can see the addresses of every account and sign transactions. If you have only External Keys for that fingerprint, you can switch only among the account indexes that those external keys include. You can see their addresses, but you cannot sign. The wallet is removed automatically when its Seed Key and all of its External Keys are removed.

Native-Segwit MultiSig Wallet

A set of fingerprints and the number of signatures required (m-of-n). As with a SingleSig wallet, you can use account indexes to keep funds separate, and each fingerprint can have its own account index. For example, a 2-of-3 multisig of fingerprints 00112233, aabbccdd, and a1b2c3d4 may be switched to account indexes (0, 7, 4). Non-zero account indexes are rarely used in multisig wallets - people usually just keep a different seed for each multisig wallet that they own (or being part of).

If you have the Seed Key for one of the fingerprints, you can add its signature to transactions (the other hardware wallets may still need to sign to complete the transaction). If you have none of the seeds, you can watch the addresses, but you cannot sign. The wallet is removed automatically if, for any of its fingerprints, the Seed Key and all of the External Keys are gone. Even in a 2-of-3 wallet, if you have the seed or the xpubs for the first two fingerprints but not for the third, you cannot find the wallet's addresses.
